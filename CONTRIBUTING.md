# Contributing to LowSpec Client

Thank you for your interest in contributing!

## Development Setup

1. Fork the repository
2. Clone your fork locally
3. Open in your IDE (IntelliJ IDEA or Eclipse recommended)
4. Ensure Java 25+ is installed
5. Build with `./gradlew build`

## Building

```bash
./gradlew build          # Build the JAR
./gradlew runClient      # Run the client for testing
./gradlew test           # Run tests
./gradlew genSources     # Generate development sources
```

## Code Style

- Follow existing Java conventions
- Use meaningful variable names
- Keep methods concise
- Add Javadoc for public APIs

## Pull Requests

1. Create a feature branch
2. Make your changes
3. Add tests for new functionality
4. Update documentation if needed
5. Submit PR with clear description

## Issues

- Use GitHub issues for bug reports and feature requests
- Follow issue templates
- Provide reproduction steps for bugs
